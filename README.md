# کافه ماموت | MAMMOTH CAFE

A premium, bilingual (Persian RTL / English LTR) website for Mammoth Cafe, built around a
scroll-driven, real-time 3D coffee experience.

> **Demo data.** The products, prices, copy and photos that ship with this project are
> placeholders. Contact details are intentionally empty. Replace everything from `/admin`
> (see [ADMIN_GUIDE.md](ADMIN_GUIDE.md)), then switch off "demo mode".

## Highlights

- **Signature hero** — a ceramic cup and saucer rendered live in WebGL (Three.js). Scrolling
  pours the coffee, builds the crema, lands the cup on its saucer, raises steam and moves the
  camera through five scenes (GSAP ScrollTrigger, pinned + scrubbed).
- **Homepage** — brand introduction, featured menu, coffee experience, gallery with lightbox,
  location & contact, footer.
- **Menu page** (`/menu`) — category navigation with scroll-spy, forgiving Persian/English
  search, sizes/variants, "popular" and "unavailable" states, prices in Toman.
- **Admin** (`/admin`) — secure login; manage products, prices, images, categories, featured
  products, gallery, contact details and working hours.
- **SEO & performance** — Persian + English metadata, hreflang, Open Graph image, sitemap,
  robots.txt, `CafeOrCoffeeShop` structured data, optimized AVIF/WebP images, self-hosted fonts,
  the 3D engine is code-split and only renders while visible.
- **Accessibility** — RTL-first, keyboard focus styles, skip link, `prefers-reduced-motion`
  (no pinning, a single calm frame), a poster fallback when WebGL is unavailable.

## Tech stack

| Area | Choice |
| --- | --- |
| Framework | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4 (design tokens in `src/app/globals.css`) |
| 3D / motion | Three.js (procedural geometry + custom GLSL), GSAP + ScrollTrigger |
| Data | JSON file store behind a storage interface (PostgreSQL-ready, see architecture doc) |
| Validation / images | Zod, sharp |
| Auth | scrypt password hash + HMAC-signed, httpOnly session cookie |

Deliberately **not** used: React Three Fiber and Framer Motion (the scene is one imperative
class and page transitions are CSS — fewer dependencies, smaller bundle) and a database server
(one cafe's menu does not need one yet).

## Quick start

Requires Node.js ≥ 20.9.

```bash
npm install
cp .env.example .env
npm run admin:setup      # asks for an admin username + password, writes the hash to .env
npm run dev              # http://localhost:3000
```

Production:

```bash
npm run build
npm start                # serves on PORT (default 3100)
```

### End-to-end tests

```bash
npm run build && npm start &          # server on :3100
E2E_ADMIN_USER=<user> E2E_ADMIN_PASS=<password> npm run test:e2e
```

Needs Playwright (`npm i -D playwright && npx playwright install chromium`) unless it is
installed globally. The admin tests create and then delete their own test records.
Screenshots are written to `tests/e2e/output/`.

## Environment variables

| Variable | Required | Purpose |
| --- | --- | --- |
| `SITE_URL` | production | Public URL, used for canonical links, sitemap and structured data |
| `PORT` | no | Port for `npm start` (default `3100`) |
| `ADMIN_USERNAME` | for admin | Admin login name |
| `ADMIN_PASSWORD_HASH` | for admin | scrypt hash, generated by `npm run admin:setup` |
| `SESSION_SECRET` | for admin | ≥ 32 random characters, signs the session cookie |
| `DATA_DIR` | no | Folder for `store.json` and uploads (default `./data`) |
| `COOKIE_SECURE` | no | Set to `false` only while testing over plain HTTP |

There is **no default admin password**. Until the three admin variables are set, `/admin`
shows setup instructions and nobody can log in. `.env` is git-ignored — never commit it.

## Project structure

```

  app/
    [locale]/            public site (fa at /, en at /en) — layout, home, menu, 404
    admin/               admin panel + server actions

scripts/                 admin setup, deploy helper
tests/                   unit + e2e
```

## Git workflow

`main` is deployable. Work on a branch, run `npm run typecheck && npm run lint && npm test && npm run build`,
open a pull request, merge, then run `./scripts/deploy.sh` on the server.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `/admin` says "not configured" | Run `npm run admin:setup`, then restart the app |
| Login succeeds but returns to the login page | You are on plain HTTP in production: set up SSL, or temporarily set `COOKIE_SECURE=false` |
| Admin forms fail behind Nginx ("Invalid Server Actions request") | Nginx must forward `Host` / `X-Forwarded-Host` (see `deploy/` example) |
| Image upload fails with 413 | Raise `client_max_body_size` in the Nginx server block |
| Menu changes disappear after a deploy | `DATA_DIR` was inside a folder that got replaced; point it outside the repo |
| The cup does not appear | WebGL is disabled/unsupported: the static poster is shown instead. Check the browser console |
